# Glossário inicial de domínio

| Termo               | Definição operacional                                                                 |
| ------------------- | ------------------------------------------------------------------------------------- |
| Cliente             | Pessoa física ou jurídica que mantém relacionamento com a Moura Solar.                |
| Lead                | Manifestação inicial de interesse ainda não qualificada.                              |
| Oportunidade        | Processo comercial específico com necessidade, responsável e desfecho próprios.       |
| Unidade consumidora | Instalação identificada pela distribuidora e associada a endereço e conta de energia. |
| Projeto-base        | Modelo reutilizável de solução e materiais; não representa a execução de um cliente.  |
| Dimensionamento     | Versão técnica calculada para uma oportunidade.                                       |
| Lista de materiais  | Quantidades previstas para uma versão técnica.                                        |
| Proposta            | Oferta comercial versionada apresentada ao cliente.                                   |
| Custo previsto      | Custo congelado no momento da composição comercial.                                   |
| Custo realizado     | Valor efetivo apurado por consumo, compra e custos adicionais.                        |
| Margem              | Relação entre receita e custo conforme fórmula financeira a definir.                  |
| Contrato            | Documento jurídico vinculado à proposta aceita.                                       |
| Projeto operacional | Unidade que coordena engenharia, suprimentos, instalação e entrega.                   |
| Reserva             | Quantidade comprometida para um projeto, ainda fisicamente no estoque.                |
| Separação           | Transferência/conferência dos itens destinados à execução.                            |
| Consumo de estoque  | Baixa efetiva do material utilizado.                                                  |
| Devolução           | Retorno auditado de material não utilizado.                                           |
| Ordem de serviço    | Autorização e roteiro de uma atividade de campo.                                      |
| Comissionamento     | Testes e validações após a instalação física.                                         |
| Pós-venda           | Período e processos posteriores à entrega, incluindo suporte e garantia.              |
